# Интерактивно Портфолио - INFORCE Internship Task

Това е интерактивно уеб приложение, създадено като практическа задача за стажантската програма на INFORCE. Проектът представлява учебен план/портфолио, което позволява добавяне, изтриване, филтриране и проследяване на цели.

## Използвани технологии
- **HTML5** – за семантичната структура на сайта.
- **CSS (Tailwind)** – за съвременен стил и имплементация на Dark/Light Mode.
- **JavaScript** – за динамичната логика, управление на DOM и обработка на събития.
- **LocalStorage API** – за съхранение на данните локално в браузъра.

## Структура на проекта
- `index.html` – съдържа HTML структурата, Tailwind CSS стиловете и пълната JavaScript логика.
- `README.md` – инструкции за стартиране и описание на проекта.
- `Documentation.txt` – подробен доклад с отчети, тестови сценарии и използвани инструменти.

## Основни функционалности
- **CRUD операции:** Добавяне и изтриване на цели.
- **Валидация:** Защита срещу празни полета, кратки текстове (под 3 символа) и дублиращи се записи.
- **Филтриране:** Преглед на всички, само активни или само завършени цели.
- **Локално съхранение:** Запазване на прогреса при презареждане на страницата.
- **Динамичен прогрес бар:** Преизчисляване на процента завършени задачи.
- **Dark Mode:** Превключване между светла и тъмна тема.
- **XSS защита:** Безопасно изобразяване на въведения текст.

## Инструкции за стартиране
1. Разархивирайте ZIP файла.
2. Отворете `index.html` с произволен съвременен браузър (Chrome, Edge, Firefox).
3. За редакция на кода се препоръчва ползването на VS Code с разширението Live Server.
